# www.silicasand.in

Production public website hosted by the Railway project `SilicaIndia-Ops`.

- `app/`: FastAPI website source.
- `portfolio/`: portfolio pages served by the website.
- `reports_pdfs/`: generated report content.
- `Procfile` and `requirements.txt`: Railway deployment configuration.
- `silica.db`: local development database.

Live URL: https://www.silicasand.in
