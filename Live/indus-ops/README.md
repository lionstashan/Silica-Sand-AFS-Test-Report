# Indus Ops

The same application source is deployed to three environments:

| Environment | URL |
| --- | --- |
| Production | https://ops.indussilicasand.in |
| Staging | https://ops-web-staging-987e.up.railway.app |
| Demo | https://demo-web-production-afc6.up.railway.app |

- `application/`: Node.js transport and operations system.
- `mobile-clients/`: Flutter and related Ops clients.

Production and staging are in the Railway project `indus-ops`. Demo is in `transport-demo`.
