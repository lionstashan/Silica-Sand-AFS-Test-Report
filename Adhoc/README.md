# Adhoc Projects

Projects in this directory are not deployed as active Silica India services. They are retained for reference and can be developed independently without changing the live Railway applications.

| Project | Status |
| --- | --- |
| `Projects/silica-ai-backend/` | Retired backend; Railway service removed |
| `Projects/silica-beneficiation-digital-twin/` | Experimental plant simulation |
| `Projects/boutique-manager/` | Independent Flutter application |
| `Projects/mittsaa-store/` | Independent nested Git repository |

The `mittsaa-store` directory keeps its own Git history and remote and is intentionally excluded from this parent repository.
